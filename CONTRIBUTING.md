# Contributing

Contributions are welcome when they improve correctness, reproducibility, source quality, forecasting discipline, tests, or maintainability.

- Keep the engine independent from the proprietary iOS client.
- Do not add F1/team logos, photography, broadcast graphics, or other third-party visual assets.
- Do not commit credentials, private datasets, or user data.
- Prefer primary/official sources where practical.
- Keep observations separate from inference and prediction.
- Run `python -m pytest` before submitting changes.

By submitting a contribution, you agree that it is licensed under Apache-2.0 unless explicitly agreed otherwise.
